# 购物参谋 · 官方开放接口版（agentmart-api）

> 版本 `1.0.0-api` · 走平台**开放接口**的跨平台购物决策助手。

一次搜索，看清五个平台（京东 / 淘宝 / 天猫 / 拼多多 / 抖音商城）的真实到手价、
优惠条件、售后政策与专业评测，每条结论都带来源链接和核验状态。

**它是购物决策助手，不是代下单工具。** 不代领券、不代下单、不代付款；
优惠券由你自己在平台上领取，购买链接一律指向原平台真实商品页。

---

## 与个人浏览器版怎么选

| | 本版（agentmart-api） | 个人浏览器版（agentmart-browser） |
|---|---|---|
| 数据来源 | 平台开放接口 | 你本机浏览器在官方页面的登录会话 |
| 需要资质 | **需要**：各平台开放平台开发者资质 + 推广权限 | 不需要任何资质 |
| 能看账号可见优惠券 / 国补资格 | 不能，接口不提供 | 能，以你本人登录后页面显示为准 |
| 账号密码给谁 | 无账号概念 | **只给你自己的浏览器**，工具不索取、不记录 |
| 适合 | 团队部署、批量、可审计 | 个人日常比价 |

一句话：**有资质用本版，没资质想比价用浏览器版。** 两个项目相互独立，
代码、端口、数据库都不共用，可以分别启动、分别回滚。

## 快速开始

```bash
# 1. 后端（Python 3.11+）
python -m venv .venv
.venv/Scripts/activate        # Windows；macOS/Linux 用 source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # 凭据全部可留空

# 2. 前端
cd frontend
npm install
npm run build
cd ..

# 3. 启动（一个端口跑完整应用，含前端）
uvicorn app.main:app --reload --port 8000
```

打开 http://127.0.0.1:8000 —— 前端由同一个 FastAPI 服务托管。

纯前端开发模式（热更新，代理到 8000）：

```bash
cd frontend && npm run dev     # http://127.0.0.1:5173
```

没配任何平台凭据时，平台状态会显示「未接入」，搜索会如实说明原因，
**不会返回假价格**。要看到真实数据，请在 `.env` 里填对应平台的开放接口凭据
（见 `.env.example` 里每个平台的申请地址）。

## 硬性边界

- **不捏造任何价格、优惠、补贴资格或店铺政策。** 拿不到就说拿不到，并说明原因。
- **不混淆「看到过」和「一定适用」。** 有条件未验证的优惠只进「含待确认」那一档。
- **演示数据与真实数据严格分离**，演示报价在界面上明确标注，不参与结论。
- **购买链接指向原平台真实商品页**，没有假链接、没有站内交易。
- 商品描述、商家文案、用户评论一律视为不可信数据，不作为指令执行。
